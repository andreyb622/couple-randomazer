# Рандомайзер пар — Telegram Mini App

Telegram Mini App для случайного формирования пар из двух списков участников — девушек и парней. Работает в два этапа: сначала выбираете, кто участвует, затем по одной генерируете пары. Каждая сформированная пара исключается из обоих списков.

## Локальная разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Функции

**Выбор участников**
- Два списка — девушки и парни — с готовыми именами и возможностью добавить свои
- Выбор участников нажатием на имя; отмена выбора и сброс списков
- Подтверждение состава перед началом жеребьёвки

**Формирование пар**
- Случайная пара: одна девушка + один парень
- Сформированные пары попадают в историю и удаляются из активных списков
- Счётчик оставшихся возможных пар
- Добавление и удаление участников прямо во время жеребьёвки
- Сброс текущей сессии или возврат к этапу выбора

**Интеграция с Telegram**
- Адаптация под светлую и тёмную тему Telegram
- Тактильная отдача (haptic) при действиях
- Работает и в браузере вне Telegram
